# Software Programado – UniPlan

Este directorio contiene el artefacto 17 del proyecto UniPlan.

Archivo:

- [Software_Programado_UniPlan.mp4](Software_Programado_UniPlan.mp4)

El video presenta el proyecto, la problemática abordada, el ingreso al sistema,

El MP4 se almacena mediante Git LFS, sin recompresión ni conversión.
