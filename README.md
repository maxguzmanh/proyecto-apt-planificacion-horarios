# Proyecto APT - Planificación y Validación de Horarios Académicos

## Asignatura
Capstone - Ingeniería en Informática

## Descripción

Proyecto orientado al desarrollo de una plataforma web para apoyar
el proceso de planificación y validación de horarios académicos en
una institución de educación superior.

Actualmente el proceso de planificación se realiza mediante múltiples
planillas Excel elaboradas por diferentes responsables, lo que puede
generar conflictos de profesores, aulas, disponibilidad docente,
carga horaria e inconsistencias durante la consolidación de la
información.

La solución propuesta permitirá centralizar la planificación y validar
automáticamente los principales conflictos antes de generar el archivo
Excel requerido por el sistema académico institucional.

## Alcance general

El sistema permitirá:

- Gestionar la estructura académica institucional.
- Registrar profesores y disponibilidad.
- Gestionar aulas y capacidades.
- Construir manualmente los horarios.
- Detectar conflictos de profesores y aulas.
- Validar disponibilidad y carga docente.
- Validar capacidad de los espacios.
- Generar un archivo Excel compatible con el formato requerido por el
  sistema académico institucional.
